# 我的课表

根据个人课表 PDF 和富春校区教学作息表制作的离线 PWA。

应用采用整周网格布局：左侧为节次和上课时间，右侧为七天课程；课程块按实际节次数延伸，当前周没有课的课程以“非本周”灰显。点击任意课程块可以查看完整课程名、场地、教师和上课周次。

完整的课程数据核对结果见本目录中的 `课程核对表.md`。

## 本地预览

在当前目录运行：

```powershell
python -m http.server 4173
```

然后在浏览器打开 `http://localhost:4173/`。

## iPhone 安装

这个网页需要先部署到支持 HTTPS 的静态网站，例如 GitHub Pages、Cloudflare Pages 或 Netlify。

部署后用 iPhone Safari 打开网址：

1. 点击底部“分享”按钮。
2. 选择“添加到主屏幕”。
3. 确认添加。

首次打开后页面会被离线缓存，之后即使断网也可以查看课表。

## 学期起始日

第 1 周从 `2026-09-14` 开始。右侧设置中可以修改起始日期，修改后周次和日期会自动重算。
